# =============================================================================
# SentinelOps - Serving Requirements
# =============================================================================
# Everything the inference API needs, and nothing else.
#
# The deployed container serves a trained Champion; it does not train, track
# experiments, or reproduce the pipeline. MLflow, DVC and Evidently are
# therefore deliberately absent -- they add hundreds of megabytes and a
# database driver to an image whose job is to load a 3.6 MB model and answer
# HTTP requests. /mlops/* reads the state the pipeline exported to
# reports/mlops_state.json, so the control panel stays fully populated without
# any of them installed.
#
#   Serving:  pip install -r requirements-api.txt
#   Pipeline: pip install -r requirements.txt
# =============================================================================
